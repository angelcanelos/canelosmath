# calculo-rapido (canelosmath)

Juego web para entrenar cálculo mental con sumas y restas rápidas, al estilo de monkeytype y tetr.io. Área: personal. Repo: `angelcanelos/canelosmath`.

## Stack
React 19 + Vite + Vitest. Documentación y capturas en `docs/` (generadas con `/clsmd`).

## Comandos
| Para | Comando |
|---|---|
| Desarrollo | `npm run dev` |
| Build | `npm run build` |
| Tests | `npm test` |

Corre `npm test` y `npm run build` antes de dar una tarea por terminada.
